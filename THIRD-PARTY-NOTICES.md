# Ownership and dependencies

This repository contains Joshua Small's Clipboard Compatibility implementation. No standalone open-source license grant is made by this initial release, consistent with the existing author's mod repositories.

The catalog thumbnail is the author's existing Avitex artwork, reused byte-for-byte from `joshua-small/qsys-better-shortcuts/catalog/artwork/avitex.ico`. It is not Q-SYS artwork.

Q-SYS Designer and ModuleCommon are proprietary QSC references and are not redistributed. Q-SYS and QSC names identify compatibility; this is an independently developed mod.

Mods Core and its pinned Harmony dependency are installed and owned by the existing Mods Core package. This package contains only its private module; it does not redistribute Core or Harmony. Harmony's license remains in the shared `AutomaticGeometry.Harmony.LICENSE.txt` file supplied by Core.
