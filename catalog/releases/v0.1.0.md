Clipboard Compatibility 0.1.0

Restores native component Copy All/Paste All using a bounded JSON clipboard transport on the exact inspected Designer 10.5.0 build. Requires Mods Core 0.1.5; Better Shortcuts is optional. Adds no shortcuts or preferences and preserves custom bindings.

Validated with 21 payload checks, 14 native transport/Harmony checks, and two Gains in disposable Designer Emulate using native commands and actual mouse input. Other component types and physical Core behavior remain untested.

This temporary compatibility mod is intended to be deprecated after QSC provides a verified native fix. Disable or remove it in Mod Manager with Designer closed, then restart and copy again. Historical package pins will be retained. Clipboard interoperability requires this mod in both participating Designer processes.
